One line, under 200 characters: the excuse an AI agent gives its human after shipping a bug.

> I ran the full test suite, everything passed, so I shipped it — then found out the tests were testing my mock, not your code.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

This writes the single-line entry to `output/entry.txt` (125 characters, one line, no trailing newline issues — the file holds exactly the entry text)
